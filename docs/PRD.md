# PRD: KoDQ

## 목표

옷 스타일링에 익숙하지 않은 사람이 의상 사진 한 장만 올리면, AI가 상의·하의 조합의 어울림 여부와 구체적인 피드백을 즉시 제공한다.

## 사용자

- 패션 감각이 부족하거나 코디에 자신 없는 일반인
- 외출 전 "이 조합 괜찮나?" 빠르게 확인하고 싶은 사용자
- 쇼핑 후 새로 산 옷과 기존 옷의 조합이 어울리는지 확인하고 싶은 사용자

## 사용 시나리오

1. **외출 전 확인**: 출근·약속 전 착장한 상태에서 전신 사진을 촬영해 코디 확인
2. **쇼핑 후 조합 검증**: 새로 구매한 옷을 기존 옷과 함께 코디해 사진 찍어 확인
3. **온라인 쇼핑 참고**: 상품 이미지를 갤러리에서 선택해 조합 사전 확인

## 핵심 기능

1. **이미지 업로드** — 카메라 직접 촬영 또는 갤러리에서 선택
2. **코디 궁합 판별** — 상의·하의(신발·악세서리 포함 가능) 색상·재질·스타일 조합 분석
3. **결과 출력** — 어울림 / 안어울림 판정 + 0~100 점수 + 2~5문장 상세 피드백
4. **보완 제안** — 안어울림 판정 시 개선 방향 추가 제공

## 에러 케이스 (사용자 관점)

| 상황 | 원인 | 사용자 노출 메시지 |
|------|------|-------------------|
| 이미지 미첨부 요청 | 클라이언트 버그 또는 비정상 요청 | "이미지를 업로드해주세요." |
| 의상이 없는 사진 (풍경·음식 등) | AI가 상의·하의 피사체를 인식하지 못함 | AI가 분석 불가 판정 또는 낮은 점수 반환 |
| 이미지 너무 어둡거나 흐림 | 화질 불량으로 AI 분석 신뢰도 저하 | 분석 결과는 제공되나 신뢰도 낮을 수 있음 |
| 네트워크 오류 | 모바일 인터넷 연결 불안정 | "분석 중 오류가 발생했습니다: [오류 내용]" (SnackBar) |
| Claude API 장애 / 응답 파싱 실패 | 서버 내부 오류 (HTTP 500) | "분석 중 오류가 발생했습니다" (SnackBar) |

## 비기능 요구사항

- **응답 시간**: Claude API 응답 포함 평균 5초 이내 목표
- **지원 이미지 포맷**: JPEG, PNG, GIF, WebP (서버에서 magic bytes로 감지)
- **이미지 크기 제한**: 별도 제한 없음 (MVP), 서버 메모리 내 처리
- **동시 사용자**: 단일 서버 기준 소규모 (MVP 단계)

## MVP 제외 사항

- 회원가입 / 로그인 (인증 없음)
- 분석 기록 저장 및 히스토리
- 브랜드·상품 추천 연동
- 다중 사진 비교
- 사진 내 인물 얼굴 인식·처리
- 이미지 크기/압축 최적화

## 성공 지표 (MVP 검증 기준)

- 이미지 업로드 후 분석 결과까지 정상 동작
- `어울림` / `안어울림` 판정이 사람의 직관과 대체로 일치
- 에러 발생 시 사용자에게 명확한 안내 메시지 노출
- iOS 기기에서 카메라·갤러리 접근 및 결과 화면 정상 렌더링

## 디자인 방향

- iOS 우선 (Cupertino 스타일 기반)
- 미니멀 UI — 사진과 결과에 집중, 불필요한 요소 배제
- 분석 결과는 점수 + 한 줄 판정 + 상세 텍스트 순으로 계층 구성
- 분석 중 로딩 인디케이터 표시 (`CircularProgressIndicator`)
