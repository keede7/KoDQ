# PRD: KoDQ

## 목표

옷 스타일링에 익숙하지 않은 사람이 의상 사진 한 장만 올리면, AI가 상의·하의 조합의 어울림 여부와 구체적인 피드백을 즉시 제공한다.

## 사용자

- 패션 감각이 부족하거나 코디에 자신 없는 일반인
- 외출 전 "이 조합 괜찮나?" 빠르게 확인하고 싶은 사용자

## 핵심 기능

1. **이미지 업로드** — 카메라 촬영 또는 갤러리에서 선택
2. **코디 궁합 판별** — 상의·하의(신발·악세서리 포함 가능) 색상·재질·스타일 조합 분석
3. **결과 출력** — 어울림 / 안어울림 판정 + 0~100 점수 + 2~5문장 상세 피드백
4. **보완 제안** — 안어울림 판정 시 개선 방향 추가 제공

## MVP 제외 사항

- 회원가입 / 로그인 (인증 없음)
- 분석 기록 저장 및 히스토리
- 브랜드·상품 추천 연동
- 다중 사진 비교
- 사진 내 인물 얼굴 인식·처리

## 디자인 방향

- iOS 우선 (Cupertino 스타일 기반)
- 미니멀 UI — 사진과 결과에 집중, 불필요한 요소 배제
- 분석 결과는 점수 + 한 줄 판정 + 상세 텍스트 순으로 계층 구성
